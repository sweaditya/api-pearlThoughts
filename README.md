# 🚀 Hello API – Express.js

This project is a simple **Node.js + Express.js REST API** created as part of an internship task.  
It demonstrates how to set up a basic server and expose a GET endpoint that returns a JSON response.

---

## 📌 Features

- Simple Express server setup
- REST API endpoint using GET method
- JSON response handling
- Beginner-friendly structure

---

## 🛠 Tech Stack

- **Node.js**
- **Express.js**
